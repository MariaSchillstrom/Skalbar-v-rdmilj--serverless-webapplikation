# Serverless Webbapplikation - Svampregistret 🍄

En enkel serverless webbapplikation som demonstrerar grundläggande AWS-tjänster och Infrastructure as Code.

## Om Projektet

Detta är ett skolprojekt för att lära sig serverless-arkitektur på AWS. Applikationen visar en lista över svampar med bilder och beskrivningar, där data hämtas dynamiskt från en databas.

**Syfte:** Visa hur man bygger en komplett serverless-applikation med:
- Static web hosting
- REST API
- Serverless backend
- NoSQL-databas
- Infrastructure as Code

## Teknisk Stack

- **Frontend:** HTML, JavaScript
- **Backend:** AWS Lambda (Python)
- **API:** API Gateway
- **Databas:** DynamoDB
- **Hosting:** S3 Static Website
- **IaC:** CloudFormation


## Dokumentation

Se **Rapport.md** för fullständig teknisk dokumentation om arkitektur, säkerhet, kostnader och implementation.

Detaljerade setup-instruktioner finns i mappen `Instruktioner/`.
